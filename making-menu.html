🍽️ Weekly Menu + Daily Hajiri

Har din ke har meal mein Recipe page se dish dropdown se add karein. Ek baar save menu har hafte chalega, jab tak aap badlein nahi.

1. Poore Hafte ka Menu Set Karein

Sunday se Saturday tak sabhi din yahin hain. Har meal mein dropdown se recipe chunein aur Add dabayein. Ek meal mein kai dishes add kar sakte hain.

2. Roz ki Hajiri — Sabhi Meals Ek Saath

Neeche aaj ke chhe meals ek saath dikhenge. Har meal ki hajiri alag tick karke alag save karein. Ek meal save karne se doosre meals band nahi honge.

3. Cook ko WhatsApp Ration
